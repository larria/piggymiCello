# 咪猪头拉大提琴 🎻

面向大提琴初学者(尤其是孩子)的单文件 Web 应用:调音器 + 节拍器。把手机或 iPad 放在琴边,咪猪头帮你听音准、打节拍。无账号、无云同步、无广告,可安装为 PWA 离线使用。

**线上地址**:https://larria.github.io/piggymiCello/

## 功能

### 调音器

- **实时音高检测**:YIN 算法(4 倍降采样 + 累积均值归一化 + 抛物线插值),低至 C2(65.4Hz)仍可精确识别,采样帧间中值滤波去抖
- **两种模式**:
  - 自动识别 —— 任意音(C2–A5),自动匹配最接近的音并高亮对应空弦
  - 手动模式 —— 锁定 C/G/D/A 单弦,偏差超过半音(±100 音分)时提示"这不是 X 弦",**绝不给出拧弦方向**,防止误拧断弦
- **可视化表盘**:±50 音分刻度盘,红/黄/绿三色分区,平滑指针,音分数值实时显示
- **调音指引**:音偏低 → "拧紧琴弦" / 音偏高 → "放松琴弦" / 准了 → 绿光高亮 + 震动
- **参考音播放**:每根弦可播放合成大提琴音色(基频 + 3 阶泛音),支持双音校弦法
- **A4 校准**:415–465Hz(巴洛克 / 440 / 乐团 442),实时联动所有目标频率
- **准音容差**:±3 / ±5 / ±10 音分可选

### 节拍器

- **BPM**:30–240,大数字 + 加减按钮 + 滑杆,实时显示速度术语(庄板/慢板/行板/中板/快板/急板…)
- **常用速档**:慢板 50 / 行板 70 / 中板 90 / 快板 120 / 急板 152 一键直达
- **拍号**:2/4、3/4、4/4、6/8(6/8 按传统习惯标两个强拍:第 1、4 拍)
- **拍点可视化**:圆点序列,当前拍放大变色,强拍珊瑚色、弱拍青绿
- **小猪点头**:节拍器页的小猪随节拍左右摇摆
- **声音**:Web Audio 合成短促打击音,强拍 1568Hz 响、弱拍 988Hz 轻
- **练习计时**:不限 / 1 / 3 / 5 分钟,实时倒计时,结束自动停止 + 完成提示
- **拍点震动**:强拍 40ms、弱拍 15ms,可关

### 练习曲(规划中)

留给后续的启蒙小曲子板块,当前为占位页。

## 使用说明

1. 浏览器打开线上地址(麦克风需要 https 环境)
2. 点击"开始调音",首次使用授予麦克风权限
3. 将琴弦拨响并持续两三秒,看指针:偏左拧紧、偏右放松,指向 0 亮绿即准
4. 建议调弦顺序:先 A 弦,再依次 D、G、C
5. 安装到主屏幕(Safari"添加到主屏幕" / Chrome"安装应用")后可离线使用

**环境建议**:安静房间,手机麦克风离琴 30–60cm;iPhone 请使用 Safari。

## 技术实现

| 项 | 说明 |
|---|---|
| 架构 | 单文件 `index.html`(约 2600 行,零依赖、零构建),`sw.js`,`manifest.json` |
| 音高检测 | YIN 算法;4 倍均值降采样后 4096 点分析,覆盖 45–1000Hz;CMND 归一化 + 阈值 0.15 + 抛物线插值细化 |
| 音频 | Web Audio API;参考音用基频 + 3 阶泛音叠加模拟大提琴音色;节拍音用短包络方波(木鱼质感) |
| 兼容 | iOS 14.4 以下无 `getFloatTimeDomainData` 时回退 `getByteTimeDomainData`;双击启动防竞态;切后台自动停节拍器/释放常亮锁 |
| 适配 | 桌面侧边栏 / ≤820px 自动变毛玻璃底部导航;`safe-area-inset` 全适配;44px 触控目标 |
| 视觉 | 手绘 SVG 角色(咪猪头拉大提琴、小猪指挥家),米纸色系 + 青绿主色,风格延续[咪猪头识字成长册](https://github.com/larria/piggymicharacter3) |

### PWA 更新机制

- Service Worker 外壳缓存(`sw.js`),支持离线打开
- **安全更新协议**:新版本下载后不立即接管;用户在页面点击版本按钮 → `SKIP_WAITING` 消息(带 MessageChannel 确认端口)→ SW 校验仅单窗口打开 → 确认后 `skipWaiting` → `controllerchange` + 消息确认双条件 reload
- 上线 / 回前台 / 网络恢复时自动后台检查更新(60 秒节流)
- 版本按钮显示 `v{版本} · 状态`(检查中/有更新/已是最新/离线…),详细提示在子行展开

## 开发与发布

```sh
npm install        # 仅安装 gh-pages 插件
npm run copy       # 复制静态文件到 dist/
npm run deploy     # copy + 推送 dist 到 gh-pages 分支(不用 GitHub Action)
```

发布新版本流程:

1. 修改代码
2. `sw.js` 中 `RELEASE` 递增(驱动缓存换代),`index.html` 中 `APP_VERSION` 与 `manifest.json` 中 `version` 同步更新
3. `git add -A && git commit -m "..." && git push`(推 main 分支)
4. `npm run deploy`(发布到 GitHub Pages)
5. 用户端:点击版本按钮即可安全更新,或等自动检查

## 目录结构

```
├── index.html      # 全部应用逻辑(HTML/CSS/JS 单文件)
├── manifest.json   # PWA 清单
├── sw.js           # Service Worker(离线缓存 + 安全更新)
├── icons/          # 应用图标(192/512/apple-touch)
├── package.json    # 仅承载 gh-pages 部署脚本
└── dist/           # 部署产物(git 忽略,由 npm run copy 生成)
```
